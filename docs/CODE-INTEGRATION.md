# 代码侧接入说明 | Code Integration

## 分工
- **Claude（代码）**：动画状态切换、混合、位移、伤害判定、客户端同步、游戏内实装与验收反馈。
- **Codex（美术）**：模型、贴图、动画、音效、特效素材。
- **鼠王**：最终确认；骨骼结构、导出格式、动画接口的变更由鼠王转交协调。

## 分支与文件归属
- 代码分支：`code/claude-integration`，不直接在 `main` 上开发。
- 代码侧只改：`src/main/java/**`、`src/gametest/**`、`gradle/*.gradle`、`build.gradle`、配置与文档。
- **代码侧不改**：`model-source/*.bbmodel`、`src/main/resources/assets/silver_samurai/{textures,sounds}/**` 及 Codex 提交的任何美术源文件。
- 运行时骨骼数据由 `compileRuntimeRigs` 从 `model-source` 只读提取到 `build/generated/runtime-rigs`，不回写源文件。
- 不自动发版，不改版本号，除非鼠王要求。
- 平台固定：Minecraft 1.20.1 / Forge 47.4.0+ / Java 17，不做 NeoForge。

## 接入规则
1. 骨骼名、动画名、持续时间、关键事件时间、衔接姿势以美术交接说明为准。
2. 不为接入方便重做已确认的动画；只在代码侧做状态切换、混合和时间对齐。
3. 需要改骨骼结构、导出格式或动画接口时，先写成"变更需求"（见下方模板），交鼠王转交。

### 变更需求模板
```
需求编号：
涉及文件 / 阶段：phase1 / phase2
涉及骨骼或动画：
现状：
需要：
原因（代码侧具体问题、复现条件）：
不改的后果 / 代码侧临时处理：
```

### 游戏内问题反馈模板
```
动画名：
阶段：
发生时间：动画内第 X.XX 秒 / 第 N 刻
问题类型：持刀 / 穿模 / 衔接 / 双阶段表现 / 位移 / 判定
复现条件：（地形、目标、距离、配置、指令）
判断：代码侧 / 美术侧 / 待定
```
